# KER v1.18.0

**Единая экосистема, этап 1: аккаунт, устройства и уведомления перестают быть
отдельными для каждого клиента — и Desktop становится главным клиентом
платформы, а не просто чат-окном.**

## 🔐 Авторизация: устранён боевой сбой

`/auth/telegram` больше не падает голой HTTP 500 — `AuthError` и сбои SQLite
теперь превращаются в внятные 401/409/503. Аккаунт с неподтверждённым
Telegram теперь находится по telegram-id, а не дублируется. Автообновление
проверяет SHA256 установщика перед запуском (сорванная/подменённая закачка
больше не выполнится). `/health` отдаёт наружу только `{"ok": true}` —
диагностика ушла в `/health/full`, доступный только владельцу.

## 🧠 Единая память

Telegram-аккаунт, слинкованный с Desktop/Web, теперь пишет в ту же память,
что и остальные клиенты — раньше это были два непересекающихся пространства
ключей даже после `/link`.

## 🖥 Device Manager

Новый экран «Устройства»: список всех когда-либо выданных сессий
(Telegram, Desktop, Web) с пометкой «в сети» для живых desktop-control
подключений — и кнопкой завершить любую из них удалённо. Раньше сервер физически
не мог ответить на вопрос «что сейчас залогинено в аккаунт»; второе
подключённое устройство молча вытесняло первое.

## 🚀 Настоящий Boot Sequence

Вместо пустого экрана на запуске (до 30 секунд молча в локальном режиме) —
сплэш с реальным статусом: проверка сессии → запуск AI Core → синхронизация.

## 🔔 Уведомления, которые наконец видно

Proactive-сообщения ассистента (локальный режим) переставали показываться
где-либо в обычной поставке из-за скрытого сбоя — починено, и теперь у всех
уведомлений (proactive, обновления, будущие события агентов) один общий
канал вместо трёх разрозненных.

## 🔑 Смена пароля

Новый эндпоинт и экран в профиле — со сверкой текущего пароля перед сменой,
чтобы забытая открытой сессия сама по себе не давала полный захват логина.

## 💬 История чата стала настоящей

Клик по элементу истории теперь реально открывает и продолжает старую
сессию — раньше это был мёртвый список.

## ✅ Verified

996 автоматических тестов, все зелёные. Новые: авторизация (обратная
совместимость метаданных устройства, throttling смены пароля, cross-tenant
изоляция для истории чата и Device Manager), NotificationCenter, AppStatus,
структурные проверки Command Deck (парность JS/секций, node --check).
Ручная проверка на живом exe — при следующем реальном запуске.
